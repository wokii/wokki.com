# wokki.com

Personal website and creative platform by Han Wokki.

- 🔴 Built with Next.js, React, and TypeScript.
- 🟠 Start locally with `npm install` and `npm run dev`.
- 🟡 Main experience lives at `/`.
- 🟢 Signature worlds: `/god`, `/mcn`, `/sas`, `/nana`, `/l`, `/c`, `/md`.
- 🔵 Consultancy page: `/consultancy`.
- 🟣 APIs: `/api/auth/[...nextauth]` and `/api/consultancy/stats`.
- ⚪ Production runs with environment variables configured and `npm run build`.
